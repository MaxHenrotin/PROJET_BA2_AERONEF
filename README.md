# ✈️ Live Aircraft Tracker from Radio Signals

Java application that receives and decodes real-time ADS-B signals from aircraft using a software-defined radio (AirSpy R2).  
The app extracts data from the binary signal like aircraft position, speed, and identity, and displays them on an interactive map.

---

## Key Components
- Binary message decoding (ADS-B format)  
- Real-time data processing  
- JavaFX-based graphical interface  
- Modular Java architecture
